# Проект приложения для анализа банковских транзакций
## Описание:
#### Приложение для анализа банковских транзакций. Приложение генерирует JSON-данные для веб-страниц, формировать Excel-отчеты, а также предоставлять другие сервисы.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Alexandr901/PythonProjectBank.git
   ```
2. Перейдите в директорию проекта:
   ```bash
   cd PythonProjectBank2
   ```
3. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

### Использование:
Точкой запуска программы является модуль main.py

### Тестирование

Для тестирования проекта используется библиотека `pytest`. 
Чтобы запустить тесты, выполните команду:

```bash
  pytest
```


- Покрытие тестами составляет более 80% кода проекта.
